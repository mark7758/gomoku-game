# 五子棋 Gomoku

一个基于 HTML5 Canvas 的五子棋小游戏，纯前端实现，无需任何依赖。

## 功能特性

- 15 路标准棋盘，Canvas 渲染
- 双人对战模式
- 人机对战模式（启发式 AI：优先取胜、其次堵截、按连子评分选点）
- 悔棋功能
- 胜负判定与平局处理

## 使用方法

直接用浏览器打开 `index.html` 即可开始游戏。

## 文件结构

```
gomoku-game/
├── index.html   # 页面结构
├── style.css    # 样式
└── game.js      # 游戏逻辑
```
